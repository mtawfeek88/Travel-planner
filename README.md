# 🗺️ Travel Planner Map

An interactive map to plan and track places you want to visit!

## Features
- Click anywhere on the map to add a place
- Mark places as: ✅ Visited | ❌ Not Yet | ⭐ Wishlist
- Search for any city in the world
- All data saved in your browser (no server needed!)
- Export your places as GeoJSON

## How to Use
1. Open `travel-planner.html` in your browser
2. Click on the map to add a location
3. Fill in the details and save
4. Click markers to view or edit places

## Technologies Used
- Leaflet.js
- OpenStreetMap
- Vanilla JavaScript
- Browser localStorage
